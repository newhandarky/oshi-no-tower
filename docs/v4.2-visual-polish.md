# MVP-v4.2 展示版視覺打磨

日期：2026-05-11

## 目標

V4.2 聚焦展示版視覺完整度，不新增戰鬥規則、不新增狀態效果，也不調整卡牌、敵人或 relic 數值。這一輪只把已預留的 `art_path` / `icon_path` 接到正式素材。

## 已接素材

- 起始牌組卡圖第一批：10 張，位於 `res://assets/cards/subaru/` 與 `res://assets/cards/botan/`。
- 敵人 intent icon：5 張，位於 `res://assets/icons/intent/`，對應 `attack`、`block`、`attack_block`、`buff`、`debuff`。
- relic icon：18 張，位於 `res://assets/icons/relic/`，依 relic id 命名。

## 顯示規則

- `CombatCardView` 會在卡牌有有效 `art_path` 時顯示卡圖；未接圖的卡仍顯示 `ART` placeholder。
- `ActorStatusView` 會在敵方 action 有有效 `icon_path` 時顯示 intent icon；缺圖時保留文字 fallback。
- 戰鬥 header 的 relic summary 會顯示目前持有 relic 的小 icon 與名稱。
- 商店 relic 商品會在卡圖區顯示 relic icon。

## 暫不處理

- 不接 `burn`、`poison`、`stun`、`draw` gameplay 狀態。
- 不替全部 reward / shop 卡補圖。
- 不改 relic pool、Boss reward、商店價格或卡牌平衡。

## 來源備份

- `generated/sprites/v4.2-card-art-v1/processed-512/`
- `generated/sprites/v4.2-intent-icons-v1/processed-128/`
- `generated/sprites/v4.2-relic-icons-v1/processed-128/`

三批素材的 `pipeline-meta.json` 皆為 `edge_touch_frames: []`。

## 下一批建議

1. 補 reward / shop 常見卡牌主視覺。
2. 若 intent icon 在 24px 實機過小，再微調 `ActorStatusView` 的 icon 尺寸與文字位置。
3. 視覺素材穩定後，再評估是否進入 Status v3，正式新增 `burn`、`poison`、`stun`。
