最近更新：2026-05-11

## 目標

MVP-v4.3 只補完目前 Subaru / Botan 所有可取得卡牌的正式 `art_path`，不新增 gameplay 狀態、不改卡牌數值、不改敵人、relic 或 reward pool。目標是讓手牌、戰鬥獎勵與商店中的卡牌不再出現 `ART` placeholder。

## 生成來源

- Subaru atlas 來源：`generated/sprites/v4.3-card-art-subaru-v1/`
- Botan atlas 來源：`generated/sprites/v4.3-card-art-botan-v1/`

Subaru 第一批 atlas 的 `subaru-hype-call` raw cell 底部太貼邊，因此正式檔使用 `generated/sprites/v4.3-card-art-subaru-v1/processed-512-hype-call/clean.png` 的單張版本；其他卡圖依 atlas 切格輸出。

## Runtime 接線

- 只擴充 `scripts/data/RuntimeDatabase.gd` 的 `CARD_ART_PATHS`。
- `RuntimeDatabase._tag_card_metadata()` 仍沿用既有邏輯，依 card id 自動補 `card["art_path"]`。
- `CombatCardView` 不需要改 schema；有效 `art_path` 會顯示 `CardArtTexture`，缺圖時仍保留 `ART` fallback。

## 驗收

自動測試覆蓋：

- `runtime_database_tests.gd`：目前所有 `database.cards` 都必須有非空且存在的 `art_path`。
- `combat_ui_layout_tests.gd`：reward 與 shop 至少各檢查一張非起始牌會顯示 `CardArtTexture`，且不顯示 `CardArtPlaceholder`。

建議手動 QA：

1. Subaru 開局進普通戰，確認手牌卡圖顯示。
2. Botan 開局進普通戰，確認手牌卡圖顯示。
3. 戰鬥勝利進 reward，確認非起始牌 reward card 有卡圖。
4. 進商店，確認 shop card 有卡圖且 relic icon 仍正常。
5. hover 卡牌，確認卡圖不擠壓卡名、費用、類別與描述。
